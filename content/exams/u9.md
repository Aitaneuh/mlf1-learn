:::quiz
? Put the five workflow steps in order.
+ create training material → provision training set → train → evaluate → adjust and optimise
- train → create material → evaluate → provision → adjust
- provision → train → create → adjust → evaluate
> And then loop back.

? A screening model for a serious, treatable disease. Which metric matters most?
+ recall
- precision
- accuracy
> Missing a sick patient (FN) is the worst error.

? An email filter that moves messages to spam with no review. Which metric matters most for the spam class?
- recall
+ precision
> False positives hide legitimate emails.

? Lowering the decision threshold of a classifier usually…
+ increases recall and decreases precision
- increases precision and decreases recall
- changes the learned weights
> More predicted positives: fewer misses, more false alarms.

? What is the validation set used for?
+ choosing models and tuning hyperparameters
- the final, unbiased performance estimate
- learning the model parameters
> The test set gives the final estimate; training learns parameters.

? Model A: 99 % training, 70 % validation. Model B: 91 % training, 89 % validation. Which is overfitting?
+ A
- B
> Large gap between training and validation performance.

? Both training and validation errors are high. Diagnosis?
+ underfitting
- overfitting
- data leakage
> The model is too simple.

? Which of these is data leakage?
+ using the final course grade as a feature to predict whether a student passes the final exam
- using attendance as a feature
- using a validation set
> The feature is not available at prediction time and nearly equals the target.

? Which is a hyperparameter?
- the split thresholds of a fitted tree
+ the learning rate
- the coefficients of a regression
> Hyperparameters are chosen; parameters are learned.

? During training, the validation loss starts increasing at epoch 12 while the training loss keeps decreasing. When should you stop?
= 12 tol=1
> Around the minimum of the validation loss (early stopping).

? Overall accuracy is high but accuracy for French emails is low. What kind of evaluation found this?
+ qualitative / sliced error analysis
- the overall F1 score
> Systematic errors appear when you break results down by group.

? “The model confuses 4 and 9 because they look similar” is…
+ a hypothesis that needs to be checked by inspecting examples
- a proven fact from the confusion matrix
> The matrix shows that, not why.
