:::quiz
? Which three drivers explain the rise of smart, data-driven applications?
+ Data availability, abundant connected computing, advances in ML algorithms and frameworks
- Faster internet, cheaper smartphones, social media
- Better spreadsheets, more programmers, open source
> The course names data, computing power and “installation artefacts” (algorithms, frameworks, skilled people).

? In traditional programming you provide data and rules. What do you provide in machine learning?
- Rules and answers
+ Data and the correct answers (examples)
- Only the answers
> ML learns the rules (the model) from examples whose answers are known.

? An API returned 20 entities and 15 were correct. What is its precision?
= 0.75
> Precision = correct results / all results returned = 15/20 = 0.75 (you can also type 75%).

? What is a “data moat”?
- A backup copy of a database
+ Data that gives a company a competitive advantage because others cannot easily reproduce it
- A firewall protecting data
> Like a moat around a castle: reviews, user contributions or collected driving data are hard for competitors to copy.

? Which statement about latency and throughput is correct?
- They are two words for the same thing
+ Latency is the time to answer one request; throughput is how many requests are handled per unit of time
- Latency is measured in requests per second
> A system can have high throughput and still high latency for each single request.

? Which of these is NOT one of Norvig's challenges for ML in production?
- Debuggability
- Testability
+ Profitability
- Robustness
> Norvig listed debuggability, interpretability, maintainability, robustness and testability.

? Word2Vec learned word vectors from text without anyone labelling word meanings. What kind of learning is that closest to?
- Supervised learning with labels
+ Learning without human labels (unsupervised / self-supervised)
- Rule-based programming
> The training signal comes from the text itself (surrounding words), not from human-provided labels.

? Two word vectors have cosine similarity close to 0. They are…
- identical
+ unrelated (roughly perpendicular)
- exact opposites
> 1 = same direction, 0 = perpendicular/unrelated, −1 = opposite.

? Which Word2Vec setting removes words that appear rarely in the training text?
- `window`
+ `min_count`
- `workers`
- `vector_size`
> `min_count` ignores words with fewer occurrences than the threshold.

? A data engineer mainly…
- only designs neural network architectures
+ builds data pipelines and systems, and integrates and evaluates ML solutions within applications
- only writes marketing reports about AI
> The course stresses that data engineers must understand ML well enough to deploy, integrate and evaluate it.
