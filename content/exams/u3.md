? A dataset of 500 customers has the columns age, income, city and `churned` (yes/no), which we want to predict. How many features are there?

> age, income and city. `churned` is the target.

? In that dataset, the feature matrix X has shape…
+ (500, 3)
- (3, 500)
- (500, 4)
> One row per customer, one column per feature (before any one-hot encoding).

? Which encoding is appropriate for the feature `city` ∈ {Bern, Biel, Thun}?
+ One-hot encoding (three 0/1 columns)
- Bern = 1, Biel = 2, Thun = 3
- Deleting the feature
> Nominal categories need one-hot encoding to avoid a fake order.

? An apartment in Thun with categories [Bern, Biel, Thun] is one-hot encoded as…
- [3]
- [0, 1, 0]
+ [0, 0, 1]
> 1 in the Thun column, 0 elsewhere.

? Education level (primary, secondary, bachelor, master) is a…
- nominal variable
+ ordinal variable
- continuous variable
> Ordered categories with not necessarily equal spacing.

? Converting “construction year 1995” into “building age 31” is an example of…
+ feature engineering
- one-hot encoding
- unsupervised learning
> Creating/transforming raw information into more useful features.

? Which values does the training algorithm adjust?
- the features
