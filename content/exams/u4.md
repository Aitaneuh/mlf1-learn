:::quiz
? Targets [10, 20], predictions [12, 17]. What is the MSE?
= 6.5
> Errors −2 and 3 → squares 4 and 9 → mean 6.5.

? Same data: targets [10, 20], predictions [12, 17]. What is the MAE?
= 2.5
> (|−2| + |3|) / 2 = 2.5.

? Why do we square errors instead of averaging them directly?
+ So positive and negative errors cannot cancel, and large errors are penalised more
- To make the numbers smaller
- Because derivatives of absolute values do not exist
> Squaring makes each error contribute positively and emphasises big mistakes.

? RMSE = 40 CHF for a rent model. Which interpretation is best?
+ A typical prediction error is around 40 CHF
- Every prediction is exactly 40 CHF off
- 40 % of predictions are wrong
> RMSE is in the target's unit; it is a typical error magnitude.

? The derivative of the loss at the current w is −6. Gradient descent will…
+ increase w
- decrease w
- keep w unchanged
> w_new = w − η·(−6) = w + 6η.

? w = 3, derivative = 20, learning rate = 0.01. New w?
= 2.8
> 3 − 0.01 · 20 = 2.8.

? One observation x = 2, y = 10, current w = 3. What is the derivative 2x(wx − y)?
= -16
> 2·2·(6 − 10) = −16 → increase w.

? The training loss grows larger with every step. Most likely cause?
- The learning rate is too small
+ The learning rate is too large (overshooting / divergence)
- There are too many epochs
> Too-large steps jump over the minimum further each time.

? 600 observations, batch size 20, 4 epochs. How many parameter updates?
= 120
> 600/20 = 30 steps per epoch × 4 = 120.

? What is an epoch?
- one parameter update
+ one complete pass over the training data
- one batch of 32 examples
> A step is one update; an epoch processes all training data once.

? Which statement about training vs prediction is correct?
+ Training adjusts parameters using targets; prediction uses fixed parameters on new features
- Prediction also updates the weights
- Training does not need targets
> Supervised training needs targets; prediction does not.

? Why evaluate on a separate test set?
+ The training loss can be optimistic; we want to know how well the model works on new observations
- The test set makes training faster
- To find the best learning rate on it
> The goal is generalisation, not memorisation. (Tuning on the test set would also be wrong — see Unit 9.)

? For linear regression with MSE and two weights, the loss surface is…
+ a smooth convex bowl with one global minimum
- a surface with many local minima
- a flat plane
> More complex models may have several minima; linear regression + MSE does not.

? Gradient descent zig-zags across a narrow valley. Which helps?
+ Scaling the features to similar ranges, or a smaller / adaptive learning rate
- Using fewer observations
- Removing the intercept
> Narrow valleys come from features on very different scales.
:::
