:::quiz
? What is the difference between `df["age"]` and `df[["age"]]`?
+ The first is a Series (1-D), the second a DataFrame with one column (2-D)
- There is no difference
- The first is a DataFrame, the second a list
> Double brackets = list of columns = DataFrame.

? `df.shape` returns `(310, 9)`. What does it mean?
+ 310 rows and 9 columns
- 310 columns and 9 rows
- 2790 values in one column
> shape = (rows, columns).

? Which option tells `read_csv` that values are separated by semicolons?
- `delimiter_type="semicolon"`
+ `sep=";"`
- `encoding=";"`
> `sep` (or `delimiter`) sets the field separator.

? A loaded file has a single column and no error was raised. The first thing to suspect is…
+ a wrong separator
- a wrong learning rate
- a missing package
> All fields were glued together → the delimiter did not match.

? Which code selects the rows where `spend` is above 1000?
+ `df[df["spend"] > 1000]`
- `df["spend" > 1000]`
- `df.iloc[spend > 1000]`
> A boolean mask inside the brackets filters rows.

? How do you get the average `spend` per `city`?
+ `df.groupby("city")["spend"].mean()`
- `df["city"].mean("spend")`
- `df.mean(by="city")`
> Split by city, take the spend column, average per group.

? What does `y.value_counts()` give for a Series of species labels?
+ the number of rows for each species
- the number of distinct species only
- the mean label
> One count per distinct value.

? Text like `Ã©` instead of `é` indicates…
+ an encoding problem
- missing values
- a date format problem
> The bytes were decoded with the wrong encoding.

? Which line selects all rows and the first 16 columns as features?
+ `X = df.iloc[:, :16]`
- `X = df.iloc[:16]`
- `X = df[:16]`
> `iloc[rows, columns]`; `df[:16]` would take the first 16 rows.
