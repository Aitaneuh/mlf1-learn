? What is printed by: `x = 4` then `x = x * 2 + 1` then `print(x)`?
= 9

? `nums = [10, 20, 30, 40, 50]`. What is `nums[-2]`?
= 40
> Negative indices count from the end: −1 is 50, −2 is 40.

? `nums = [10, 20, 30, 40, 50]`. What is `nums[1:4]`?
- `[10, 20, 30, 40]`
+ `[20, 30, 40]`
- `[20, 30, 40, 50]`
> From position 1 up to, but not including, position 4.

? Which line correctly creates the list of predictions `w * x` for every `x` in `xs`?
+ `[w * x for x in xs]`
- `[for x in xs: w * x]`
- `w * xs` (with xs a Python list)
> The comprehension builds a new list. With a *list*, `w * xs` would repeat the list w times (or fail if w is a float); with a NumPy array it would work.

? What does this function return for `f([1, 2, 3])`?
```python
def f(values):
    total = 0
    for v in values:
        total += v
```
- 6
+ `None`
- 0
> There is no `return` statement, so the function returns None.
